# RVC Use Case Description

## 1. 현재 단계

현재 단계는 Requirements (Revision)이다. 본 문서는 `rvc-controller`의 자동 진공 청소 제어 로직 유스케이스 변경을 정의한다.

## 2. 액터

| 액터 | 설명 |
|---|---|
| 사용자 | 청소 시작 및 종료 버튼을 누르는 외부 액터 |
| 전방 센서 하드웨어 | 전방 장애물 interrupt 입력을 제공하는 외부 actor |
| 측면 센서 하드웨어 | [수정] 좌측 장애물 polling 입력을 제공하는 외부 actor이다. (수정 전: 좌측 및 우측 장애물 polling 입력을 제공하는 외부 actor) |
| 먼지 센서 하드웨어 | [수정] 먼지 감지 polling 입력을 제공하는 외부 actor (수정 전: 먼지 감지 입력을 제공하는 외부 actor) |
| Movement Motor | `rvc-controller`의 이동 명령을 수신하는 외부 actuator |
| Cleaning Motor | `rvc-controller`의 흡입 명령을 수신하는 외부 actuator |

## 3. 유스케이스 목록

| ID | 유스케이스 | 주요 관련 요구사항 |
|---|---|---|
| UC-001 | 자동 진공 청소 시작 | RVC-FR-001, RVC-FR-021, RVC-FR-022, RVC-FR-030, RVC-FR-031, RVC-FR-032 |
| UC-002 | 자동 진공 청소 종료 | RVC-FR-002, RVC-FR-020, RVC-FR-030, RVC-FR-031, RVC-FR-033 |
| UC-003 | 전방 장애물 회피 | RVC-FR-004 ~ RVC-FR-010, RVC-FR-015, RVC-FR-016, RVC-FR-030, [추가] RVC-FR-034 ~ RVC-FR-038 |
| UC-004 | 삼방향 장애물 처리 | RVC-FR-011 ~ RVC-FR-016, RVC-FR-030, [추가] RVC-FR-036 ~ RVC-FR-038 |
| UC-005 | 먼지 감지에 따른 흡입 강화 | RVC-FR-017 ~ RVC-FR-029, RVC-FR-031, [추가] RVC-FR-039 |

## 4. UC-001 자동 진공 청소 시작

| 항목 | 내용 |
|---|---|
| 주요 액터 | 사용자 |
| 목적 | 사용자가 버튼 입력으로 RVC의 자동 진공 청소를 시작한다. |
| 사전조건 | RVC가 OFF 상태이다. |
| 사후조건 | RVC는 전원 ON 상태가 되고 NORMAL 흡입 상태로 전진을 시작한다. |
| 관련 요구사항 | RVC-FR-001, RVC-FR-021, RVC-FR-022, RVC-FR-003, RVC-FR-030, RVC-FR-031, RVC-FR-032 |

### 기본 흐름

1. 사용자가 청소 시작 버튼을 입력한다.
2. RVC는 OFF 상태에서 전원 ON 상태로 전환한다.
3. [수정] RVC는 전방 센서 하드웨어, 좌측 센서 하드웨어, 먼지 센서 하드웨어와의 센서 인터페이스를 초기화한다. (수정 전: RVC는 전방 센서 하드웨어, 측면 센서 하드웨어, 먼지 센서 하드웨어와의 센서 인터페이스를 초기화한다.)
4. RVC는 cleaning motor에 NORMAL 흡입 명령을 제공한다.
5. RVC는 movement motor에 전진 명령을 제공한다.

### 예외 흐름

- 현재 요구사항에서는 별도 예외 흐름을 정의하지 않는다.

## 5. UC-002 자동 진공 청소 종료

| 항목 | 내용 |
|---|---|
| 주요 액터 | 사용자 |
| 목적 | 사용자가 버튼 입력으로 RVC의 자동 진공 청소를 종료한다. |
| 사전조건 | RVC가 전원 ON 상태이다. |
| 사후조건 | RVC는 OFF 상태가 되고 자동 청소 제어 로직과 진공 흡입 동작을 수행하지 않는다. |
| 관련 요구사항 | RVC-FR-002, RVC-FR-020, RVC-FR-030, RVC-FR-031, RVC-FR-033 |

### 기본 흐름

1. 사용자가 청소 종료 버튼을 입력한다.
2. [수정] RVC는 현재 RVC state에 정의된 종료 절차를 시작한다. (수정 전: RVC는 청소 동작을 종료한다.)
3. [수정] RVC는 현재 RVC state에 정의된 movement motor 종료 명령을 제공한다. (수정 전: RVC는 movement motor에 정지 명령을 제공한다.)
4. [수정] RVC는 현재 RVC state에 정의된 cleaning motor 종료 명령을 제공한다. (수정 전: RVC는 cleaning motor에 OFF 흡입 명령을 제공한다.)
5. [수정] RVC는 현재 RVC state에 정의된 종료 절차에 따라 전방 센서 하드웨어, 좌측 센서 하드웨어, 먼지 센서 하드웨어와의 센서 인터페이스를 종료한다. (수정 전: RVC는 전방 센서 하드웨어, 측면 센서 하드웨어, 먼지 센서 하드웨어와의 센서 인터페이스를 종료한다.)
6. RVC는 OFF 상태로 전환한다.

### 예외 흐름

- [수정] 청소 종료 버튼 입력이 발생하면 현재 RVC state에 정의된 종료 절차를 수행한 후 OFF로 전환한다. (수정 전: 청소 종료 버튼 입력이 회전, 후진, POWER_UP 중 발생했을 때의 처리 우선순위는 아직 확정되지 않았다.)

## 6. UC-003 전방 장애물 회피

| 항목 | 내용 |
|---|---|
| 주요 액터 | 전방 센서 하드웨어, 측면 센서 하드웨어, Movement Motor |
| 목적 | [수정] 전진 중 전방 장애물이 감지되었을 때 좌측 센서 입력과 90도 우회전 후 전방 센싱을 통해 회피 방향을 결정한다. (수정 전: 전진 중 전방 장애물이 감지되었을 때 좌우 장애물 상태에 따라 회피 방향을 결정한다.) |
| 사전조건 | RVC가 전진 중이다. |
| 사후조건 | RVC는 회전 완료 후 다시 전진한다. |
| 관련 요구사항 | RVC-FR-004 ~ RVC-FR-010, RVC-FR-015, RVC-FR-016, RVC-FR-030, [추가] RVC-FR-034 ~ RVC-FR-038 |

### 기본 흐름

1. 전방 센서 하드웨어가 전방 장애물 interrupt를 제공한다.
2. RVC는 movement motor에 정지 명령을 제공한다.
3. [추가] RVC는 cleaning motor에 OFF 흡입 명령을 제공한다.
4. [수정] RVC는 측면 센서 하드웨어에서 좌측 장애물 값을 확인한다. (수정 전: RVC는 측면 센서 하드웨어에서 좌측 및 우측 장애물 값을 확인한다.)
5. 전방 장애물만 감지된 경우 RVC는 movement motor에 좌회전 명령을 제공한다.
6. [수정] 전방 및 좌측 장애물이 감지된 경우 RVC는 우측 경로 확인을 위해 90도 우회전한다. (수정 전: 전방 및 좌측 장애물이 감지된 경우 RVC는 movement motor에 우회전 명령을 제공한다.)
7. [삭제] 전방 및 우측 장애물이 감지된 경우 RVC는 movement motor에 좌회전 명령을 제공한다.
8. [추가] RVC는 90도 우회전 완료 후 전방 센서 하드웨어에서 장애물 값을 확인한다.
9. [추가] 우회전 후 전방 장애물이 감지되지 않으면 RVC는 기존 전방 및 좌측 장애물 조건의 회피 결과로 보고 cleaning motor에 NORMAL 흡입 명령을 제공한 후 우회전한 방향으로 전진한다.
10. [추가] 우회전 후 전방 장애물이 감지되면 RVC는 기존 전방, 좌측, 우측 장애물이 모두 존재하는 상황으로 보고 90도 좌회전하여 원래 방향으로 복귀한다.
11. [추가] 원래 방향으로 복귀한 후 UC-004 삼방향 장애물 처리로 이어진다.
12. [수정] 회전 모드 진입 후 4초가 지나면 RVC는 회전 완료로 간주한다. (수정 전: 회전 모드 진입 후 10초가 지나면 RVC는 회전 완료로 간주한다.)
13. [수정] RVC는 cleaning motor에 NORMAL 흡입 명령을 제공한 후 다시 전진한다. (수정 전: RVC는 다시 전진한다.)

### 대안 흐름

- [수정] 90도 우회전 완료 후 전방 장애물이 감지되어 90도 좌회전으로 원래 방향에 복귀하면 UC-004 삼방향 장애물 처리로 이어진다. (수정 전: 전방, 좌측, 우측 장애물이 모두 감지되면 UC-004 삼방향 장애물 탈출로 이어진다.)

## 7. UC-004 삼방향 장애물 처리

| 항목 | 내용 |
|---|---|
| 주요 액터 | 전방 센서 하드웨어, 측면 센서 하드웨어, Movement Motor |
| 목적 | [수정] 기존 전방, 좌측, 우측 장애물이 모두 존재하는 상황을 우측 센서 입력 없이 90도 우회전 후 전방 센싱과 1 tick 후진 반복으로 처리한다. (수정 전: 전방, 좌측, 우측 장애물이 모두 감지된 상황에서 후진 후 장애물이 해제된 방향으로 탈출한다.) |
| 사전조건 | [수정] 전방 및 좌측 장애물이 감지된 상태에서 90도 우회전 완료 후 전방 장애물이 감지되었고, RVC가 90도 좌회전으로 원래 방향에 복귀한 상태이다. controller는 직접적인 우측 센서 입력을 판단에 사용하지 않는다. (수정 전: 전방, 좌측, 우측 장애물이 모두 감지되었다.) |
| 사후조건 | RVC는 회전 완료 후 다시 전진한다. |
| 관련 요구사항 | RVC-FR-011 ~ RVC-FR-016, RVC-FR-030, [추가] RVC-FR-036 ~ RVC-FR-038 |

### 기본 흐름

1. [수정] RVC는 90도 우회전 완료 후 전방 장애물이 감지되었고 원래 방향으로 복귀한 상태임을 확인한다. (수정 전: RVC는 전방, 좌측, 우측 장애물이 모두 감지된 것을 확인한다.)
2. RVC는 movement motor에 정지 명령을 제공한다.
3. [추가] RVC는 cleaning motor에 OFF 흡입 명령을 제공한다.
4. [수정] RVC는 원래 방향 복귀 상태에서 3방향 장애물 처리 루프를 시작한다. (수정 전: RVC는 movement motor에 후진 명령을 제공한다.)
5. [수정] RVC는 원래 방향에서 movement motor에 1 tick 후진 명령을 제공한다. (수정 전: RVC는 후진 중 측면 센서 하드웨어에서 좌측 및 우측 장애물 값을 확인한다.)
6. [수정] RVC는 1 tick 후진 후 측면 센서 하드웨어에서 좌측 장애물 값을 확인한다. (수정 전: 좌측 장애물이 먼저 감지되지 않게 되면 RVC는 movement motor에 좌회전 명령을 제공한다.)
7. [수정] 좌측 장애물이 감지되지 않으면 RVC는 90도 좌회전을 완료한 후 cleaning motor에 NORMAL 흡입 명령을 제공하고 전진한다. (수정 전: 우측 장애물이 먼저 감지되지 않게 되면 RVC는 movement motor에 우회전 명령을 제공한다.)
8. [수정] 좌측 장애물이 계속 감지되면 RVC는 우측 경로 확인을 위해 90도 우회전을 완료한 후 전방 센서 하드웨어에서 장애물 값을 확인한다. 우측 경로 확인 전 좌측 센서 확인은 1 tick마다 수행한다. (수정 전: 좌측 및 우측 장애물이 동시에 감지되지 않게 되면 RVC는 movement motor에 좌회전 명령을 제공한다.)
9. [추가] 우회전 후 전방 장애물이 감지되지 않으면 RVC는 cleaning motor에 NORMAL 흡입 명령을 제공하고 우회전한 방향으로 전진한다.
10. [추가] 우회전 후 전방 장애물이 감지되면 RVC는 90도 좌회전하여 원래 방향으로 복귀한 뒤 1 tick 후진, 좌측 장애물 확인, 필요한 경우 우측 경로 확인을 반복한다.
11. [수정] 회전 모드 진입 후 4초가 지나면 RVC는 회전 완료로 간주한다. (수정 전: 회전 모드 진입 후 10초가 지나면 RVC는 회전 완료로 간주한다.)
12. [수정] RVC는 탈출 방향이 결정되면 cleaning motor에 NORMAL 흡입 명령을 제공한 후 다시 전진한다. (수정 전: RVC는 다시 전진한다.)

### 예외 흐름

- 후방 장애물은 현재 요구사항 범위에서 감지하지 않는다.
- 후진 최대 허용 시간은 현재 요구사항 범위에서 정의하지 않는다.
- [추가] simulator가 제공하는 우측 장애물 정보는 controller 판단 입력으로 사용하지 않으며, 검증 결과 분석을 위한 관찰 데이터로만 사용한다.

## 8. UC-005 먼지 감지에 따른 흡입 강화

| 항목 | 내용 |
|---|---|
| 주요 액터 | 먼지 센서 하드웨어, Cleaning Motor |
| 목적 | 먼지가 감지되면 진공 흡입 상태를 POWER_UP으로 전환하고 3초 단위로 유지 여부를 판단한다. |
| 사전조건 | RVC가 전원 ON 상태이다. |
| 사후조건 | 전진 중 먼지가 계속 감지되면 POWER_UP이 유지되고, 먼지가 감지되지 않으면 NORMAL로 복귀한다. |
| 관련 요구사항 | RVC-FR-017 ~ RVC-FR-029, RVC-FR-031, [추가] RVC-FR-039 |

### 기본 흐름

1. [수정] RVC는 먼지 센서 하드웨어에서 먼지 감지 값을 1 tick마다 polling한다. (수정 전: 먼지 센서 하드웨어가 먼지 감지 입력을 제공한다.)
2. RVC는 cleaning motor에 POWER_UP 흡입 명령을 제공한다.
3. RVC는 POWER_UP 상태를 3초 동안 유지한다.
4. 3초 경과 후 RVC는 먼지 감지 값을 다시 확인한다.
5. 먼지가 다시 감지되면 RVC는 POWER_UP 상태를 유지하고 3초 타이머를 다시 시작한다.
6. 먼지가 감지되지 않으면 RVC는 cleaning motor에 NORMAL 흡입 명령을 제공한다.

### 대안 흐름

1. [수정] RVC가 정지, 회전, 후진 중이다. (수정 전: 정지, 회전, 후진 중 먼지가 감지된다.)
2. [수정] RVC는 먼지 감지 값으로 즉시 POWER_UP에 진입하지 않고 cleaning motor OFF 상태를 유지한다. (수정 전: RVC는 즉시 POWER_UP으로 전환하지 않고 NORMAL 상태를 유지한다.)
3. [수정] RVC는 정지, 회전, 후진 중 먼지 감지 값을 이후 POWER_UP 진입 조건으로 저장하지 않는다. 직진 주행을 시작하는 tick의 dust polling 결과로 흡입 상태를 판단한다. (수정 전: 이후 전진을 시작할 때 POWER_UP으로 진입한다.)
